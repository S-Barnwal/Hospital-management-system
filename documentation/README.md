## The project in one paragraph

**MediCore HMS** is an online Hospital Management System sold as a subscription (this is called **SaaS** — *Software as a Service*). A hospital visits the website, picks a plan, pays online, and instantly gets its **own private workspace**. Inside, staff register patients, book appointments, run OPD, admit patients to beds, run the laboratory and pharmacy, make bills, record expenses and see reports. Many hospitals use the **same software at the same time**, but each one can only ever see **its own data** — like flats in one apartment building: same building, separate locked doors.
